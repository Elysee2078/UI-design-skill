## What this repository changes

The thread is a discovery list, not an implementation architecture. This repository therefore does **not** dump all 15 resources into a frontend dependency graph.

Instead it separates them into:

- live agent knowledge (MCP/CLI);
- installable open-source components/tokens;
- developer tools/generators;
- reference/inspiration catalogs;
- mixed-license resources;
- premium resources.

See `source-catalog.md` for the operational classification and current license boundaries captured during preparation.
